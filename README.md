# 전도회별 집밥프로젝트

앞 화면의 QR코드로 휴대폰이 접속해, 문제가 나오면 답을 제출하고 전도회별 순위를 매기는 실시간 퀴즈입니다.

- 남전도회 6곳, 여전도회 16곳
- 전도회를 고르고 이름을 입력해 여러 명이 함께 참여
- 객관식 · O/X · 주관식, 정답 10점 · 오답 0점
- 순위는 전도회별 참여 인원의 평균 점수
- 진행자 화면: 서버 주소를 그대로 열기 / 참가자: 화면의 QR 또는 링크

## 실행

```bash
npm install
```

```bash
npm start
```

## 문제 넣기

- 처음 열면 `data/기말고사100.json`의 기말고사 예상문제 100개가 들어 있습니다 (엑셀본: `samples/집밥_기말고사_100문제.xlsx`).
- 메인 화면의 「파일로 문제 올리기」나 화면에 파일 끌어다 놓기로 문제를 추가합니다.
- 읽을 수 있는 파일: 한글(.hwp, .hwpx), 워드(.docx), PDF, 엑셀(.xlsx, .xls, .ods), CSV, 메모장(.txt), 파워포인트(.pptx), 오픈오피스(.odt)
- 시험지와 답지가 따로 있으면 두 파일을 함께 고릅니다. 문제 번호로 정답을 짝지어 줍니다.
- 주관식 정답에서 쉼표는 "모두 써야 정답", `|` 는 "둘 중 하나만 써도 정답"입니다.

화면을 고칠 때는 `src/template.html`을 수정한 뒤 `npm run build`로 `index.html`을 다시 만듭니다.

Render에는 `render.yaml` 설정으로 올립니다.
